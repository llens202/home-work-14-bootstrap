Bootstrap – це інструментарій відкритого коду для розробки з використанням HTML, CSS і JavaScript. Ми використовуємо його для створення адаптивних і мобільно-оптимізованих веб-сайтів. Він надає нам готові стилі та компоненти, що дозволяє швидко розробляти інтерфейси користувачів, не починаючи з нуля. Bootstrap містить систему сітки для створення макетів сторінок, компоненти інтерфейсу, такі як кнопки, картки, модальні вікна, і JavaScript плагіни для додавання інтерактивності до веб-сторінок. Його використання спрощує і прискорює процес розробки веб-сайтів, роблячи їх одночасно сумісними з різними пристроями та браузерами.

Framework - це набір бібліотек та інструментів, які ми використовуємо для спрощення розробки програмного забезпечення. Він надає готову структуру, яку ми можемо використовувати для створення своїх додатків, що дозволяє нам зосередитися на основній логіці, а не на низькорівневих деталях.

Бібліотека (library) – це зібрання попередньо написаного коду, яке ми використовуємо у своїх програмах для вирішення специфічних задач. Вона містить функції, класи, об'єкти та інші елементи програмування, які дозволяють нам не писати код з нуля для загальних задач. Використовуючи бібліотеки, ми можемо значно зменшити час розробки та підвищити надійність своїх додатків, оскільки ці бібліотеки зазвичай проходять ретельне тестування та оптимізацію.
